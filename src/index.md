# 考え方から理解する現代統計学

統計手法の**発想・使いどころ・数式の意味・限界**を、例題と演習を通して体系的に学ぶための日本語のオンライン教科書です。

統計学を一度学んだことがある読者を対象とし、数式の暗記よりも「なぜその手法を使うのか」「結果をどう解釈するのか」を重視しています。

> **本書の目的と制作方法について**  
> 本書は制作者が**私的な学習・復習と理解の整理のために制作**したものです。本文・数式の説明・例題・演習などの生成や改訂に**生成AI（ChatGPT）を利用しています**。**私的な学習用として一通り完成しています。** 内容には誤りが残る可能性があるため、学習中に見つかった点は随時修正します。研究や重要な判断に利用する場合は、原典・信頼できる資料でも確認してください。

全10部・58章の本文・例題・演習を公開し、**私的学習用教材としての制作は一区切り**としています。章によって説明量に違いはありますが、必要に応じて追記・訂正します。数値例は原則として学習用の仮想的な例です。

**[再現可能な計算例](reproduce.html)** — Node.jsだけで回帰・分散分析・差の差・ブートストラップなどの計算を追試できます。

**[参考資料と検証の進め方](references.html)** — 外部の公開教材と、数式・仮定を独立に確認するための手順をまとめています。

**[統計学の用語集](glossary.html)** — 標準誤差、信頼区間、相関と因果など、混同しやすい用語を章へのリンク付きで整理しています。
