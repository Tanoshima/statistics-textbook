# 考え方から理解する現代統計学

統計手法の**発想・使いどころ・数式の意味・限界**を、例題と演習を通して体系的に学ぶための日本語のオンライン教科書です。

統計学を一度学んだことがある読者を対象とし、数式の暗記よりも「なぜその手法を使うのか」「結果をどう解釈するのか」を重視しています。

> **本書の目的と制作方法について**  
> 本書は制作者が**私的な学習・復習と理解の整理のために制作**したものです。本文・数式の説明・例題・演習などの生成や改訂に**生成AI（ChatGPT）を利用しています**。内容に誤りが含まれる可能性があり、全章の独立した数式検証や専門家査読が完了したものではありません。重要な判断や研究で利用するときは原典・信頼できる資料で確認してください。

全10部・58章の本文を公開しています。章によって説明の深さに差があるため、現在も加筆・訂正・検証を継続しています。数値例は原則として学習用の仮想的な例です。
