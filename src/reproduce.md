# 再現可能な計算例

このページは、本文の主要な計算を**手元のNode.js 26で再現する**ための案内です。データはすべて**私的な学習用に作成した架空の数値**で、実際の研究結果ではありません。計算手順と説明の草案・改訂に生成AI（ChatGPT）を利用しています。

## 使い方

リポジトリを取得し、ルートディレクトリで次を実行します。

```sh
node examples/reproduce.mjs
```

外部パッケージのインストールやネットワーク接続は必要ありません。スクリプトは計算結果を表示し、計算上の整合性が崩れたときはエラーで終了します。

[計算例のソースコード（GitHub）](https://github.com/Tanoshima/statistics-textbook/blob/main/examples/reproduce.mjs)

## 実行例を読む際の注意

- **スクリプトで正しい数値が出ることは、分析の仮定が正しいことを意味しません。** 例えば差の差15を因果効果と読むためには平行トレンド等の仮定が必要です。
- **ブートストラップの標本は独立な新しい母集団標本ではありません。** 元データからの復元抽出です。シードを固定した同じ実装なら同じ結果を再現できますが、この教材の5件の値は実際の推定精度を保証しません。
- **数値例の検算は全章の数学的な正しさを保証しません。** これらのプログラムは学習の助けであり、専門的な査読の代わりではありません。
