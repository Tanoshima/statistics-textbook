## 数式・計算記号の読み方

この節は、統計学の数式でよく使う**基本的な演算と表記**を、章へのリンクなしで確認できる一覧です。記号の具体的な意味（何の平均・何の確率など）は数式ごとに変わるため、各章の式の直前・直後でも説明します。

| 表記 | 読み方・意味 | 短い例 |
|---|---|---|
| $=$, $\neq$, $\approx$ | 等しい、等しくない、おおよそ等しい | $1/3\approx0.333$ |
| $<$, $\leq$, $>$, $\geq$ | より小さい、以下、より大きい、以上 | $x\geq0$ は0以上 |
| $a+b$, $a-b$, $ab$, $a/b$ | 加算、減算、乗算、除算 | $2(3+1)=8$ |
| $a^2$, $a^k$ | 2乗、$k$ 乗（べき乗） | $3^2=9$ |
| $\sqrt a$ | 平方根（通常は非負の平方根） | $\sqrt9=3$ |
| $\lvert a\rvert$ | 絶対値。符号を除いた大きさ | $\lvert-4\rvert=4$ |
| $\sum_{i=1}^{n}x_i$ | シグマ・総和。$i$ を1から $n$ まで動かして $x_i$ を合計する | $\sum_{i=1}^{3}i=1+2+3=6$ |
| $\prod_{i=1}^{n}x_i$ | パイ・総積。順に掛け合わせる | $\prod_{i=1}^{3}i=1\times2\times3=6$ |
| $x_i$, $x_{ij}$ | 添字。$i$ 番目の値、$i,j$ で指定した値など | $x_2$ は2番目の値 |
| $\bar{x}$ | 上線（バー）。統計学では標本平均を表すことが多い | $\bar{x}=(x_1+\cdots+x_n)/n$ |
| $\hat\theta$ | ハット。母数 $\theta$ の推定値・推定量などを表す慣用的な記法 | $\hat\theta$ |
| $\log x$ | 対数。$\log_b x=y$ は $b^y=x$ の意味。統計学では底を省略した $\log$ は自然対数（底 $e$）を指すことが多い | $\log(e)=1$（自然対数の場合） |
| $\ln x$ | 自然対数。底が $e\approx2.718$ の対数 | $\ln1=0$ |
| $\exp(x)$, $e^x$ | 指数関数。同じ値を表し、自然対数と逆の関係にある | $\exp(\log2)=2$（自然対数の場合） |
| $\infty$ | 無限大。通常の有限数ではない | $n\to\infty$ |
| $\to$, $\lim$ | 近づく、極限 | $\lim_{n\to\infty}1/n=0$ |
| $\partial$, $\frac{d}{dx}$ | 偏微分、微分。ある変数を少し変えたときの変化率 | $\frac{d}{dx}x^2=2x$ |
| $\int_a^b f(x)\,dx$ | 定積分。区間 $[a,b]$ での符号付き面積・連続量の合計 | $\int_0^1x\,dx=1/2$ |
| $P(A)$ | 事象 $A$ の確率 | $P(A)=0.2$ |
| $P(A\mid B)$ | $B$ が起きた条件のもとで $A$ が起こる条件付き確率 | 縦線 $\mid$ は「…という条件で」 |
| $E[X]$ | 確率変数 $X$ の期待値 | $E[X]=\mu$ と書くことがある |
| $\operatorname{Var}(X)$ | 確率変数 $X$ の分散 | $\operatorname{Var}(X)=\sigma^2$ と書くことがある |
| $\operatorname{SD}(X)$, $\operatorname{SE}(\hat\theta)$ | 標準偏差（standard deviation）、推定量の標準誤差（standard error） | SE はデータの散らばりそのものではなく推定の不確実性 |
| $\mu$, $\sigma$, $\sigma^2$ | ミュー、シグマ。慣用的には母平均、母標準偏差、母分散 | 数式の文脈に従って読み替える |
| $\alpha$, $\beta$, $\theta$, $\lambda$ | アルファ、ベータ、シータ、ラムダ。係数・母数・水準などに使う文字 | 意味は式ごとに明示する |
| $\epsilon$, $\varepsilon$ | イプシロン。誤差項などによく使う | 誤差の定義はモデルごとに異なる |
| $\in$, $\subseteq$ | 集合に属する、部分集合である | $x\in A$ |
| $\forall$, $\exists$ | すべての、存在する | $\forall i$ は「すべての $i$」 |
| $\mathbb{R}$ | 実数全体の集合 | $x\in\mathbb{R}$ |
| $\sim$ | 分布に従う、または漸近的な関係など。文脈で異なる | $X\sim N(0,1)$ は標準正規分布に従う |
| $\propto$ | 比例する | $f(x)\propto g(x)$ |
| $\operatorname{argmax}$, $\operatorname{argmin}$ | 関数を最大・最小にする引数（値そのものではない） | $\operatorname{argmin}_x(x-2)^2=2$ |
| $\lVert v\rVert$ | ノルム。ベクトルの大きさなど | $\lVert(3,4)\rVert=5$（ユークリッドノルム） |
| $^\top$, $^{-1}$ | 転置、逆行列（数では逆数にも使う） | $A^\top$, $A^{-1}$ |

**大文字・小文字の区別：** $X$ は確率変数、$x$ は実現値として使うことが多い。同様に $\bar X$ は標本平均という確率変数、$\bar x$ は実際に観測された標本平均の値を表すことがある。すべての文献に共通する強制的な規則ではない。

**省略された底に注意：** $\log$ は分野や文献によって底が異なる。本文では断りがなければ自然対数として扱い、異なる底を使う場合は $\log_{10}$ などと明記する。

## 特に混同しやすいこと

**観測された件数と期待件数**は異なる。観測件数は非負整数だが、予測平均や期待件数は1.7件などの小数でもよい。

**相関と因果**は異なる。相関が高いことは、片方を操作すると他方が変化することの証明ではない。

**p値と仮説の確率**は異なる。頻度論のp値は「帰無仮説が真である確率」を返すわけではない。

**信頼区間と信用区間**は異なる。前者は繰り返した区間構成の被覆率、後者は条件づけた事後分布の確率に基づく。

**適合度と予測性能**は異なる。学習データの $R^2$ が高くても、未知データに対する精度は別に検証しなければならない。
